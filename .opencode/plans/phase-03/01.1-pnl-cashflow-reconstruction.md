# Phase 3 — Smart Money Detection — PnL Cashflow Reconstruction

> **Goal**: Replace the broken `/positions`-based PnL computation with a cash-flow reconstruction using Polymarket's `/activity` endpoint, fixing extreme ROI outliers and providing audit-grade PnL accuracy.
> **AI Agent Instructions**: Fix the mapping bug in `load_positions.py`, create a new `ingestion_pnl` pipeline with its data loader, transformer, exporter, and migration. Update downstream analytics pipelines to use the new PnL data.

---

## The Problem

### Bug #1: `total_pnl` incorrectly mapped

In `magic/default_repo/data_loaders/load_positions.py:70-72`:

```python
# CURRENT (WRONG)
"realized_pnl":   p.get("realizedPnl"),       # ✅ Realized PnL
"unrealized_pnl": p.get("cashPnl"),           # ❌ cashPnl = TOTAL PnL, not unrealized
"total_pnl":      p.get("cashPnl"),           # ❌ duplicate of cashPnl
```

The Polymarket API documents `cashPnl` as the **total PnL** (realized + unrealized). So `unrealized_pnl` should be `cashPnl - realizedPnl`.

**Consequence**: In `compute_wallet_metrics.py:134` and `compute_category_metrics.py:81`:
```python
total_pnl = total_realized_pnl + total_unrealized_pnl
         = sum(realizedPnl) + sum(cashPnl)  
         = sum(realizedPnl) + sum(realizedPnl + unrealizedPnl)  
         = ❌ DOUBLE-COUNT of realizedPnl
```

### Bug #2: Auto-redeemed winning positions disappear

When a market resolves and a winning position is auto-redeemed to USDC, the position **completely disappears** from the `/positions` API. Only losing or unresolved positions remain visible.

**Direct impact on the failing test**: Wallet `0x645a9…` in the Geopolitics category has:
- `total_cost_basis` = $63 (from trades, reliable)
- `total_pnl` = -$8,421 (from positions — only losing ones visible)
- ROI = -13,367% (outside test bound)

Winning Geopolitics positions were auto-redeemed and vanished. Only the losses remain visible.

## Solution Architecture

```
Polymarket Data API
  │
  ├── /activity?user={wallet}&limit=500&end={cursor}    (NEW)
  │   └── events: TRADE (BUY/SELL), REDEEM, MERGE, SPLIT, REBATE
  │
  ├── /positions?user={wallet}                          (existing, FIXED)
  │   └── currentValue = size × curPrice (open positions)
  │
  └── /trades?user={wallet}&limit=500&offset=0         (existing, unchanged)
      └── for cost_basis, volume, etc.

NEW PIPELINE ingestion_pnl:

  load_activity (API → DataFrame events)
       │
       ▼
  load_open_positions (PG → open positions)
       │
       ▼
  compute_pnl_from_activity (transformer)
       │  PnL = Σ(sell + redeem + merge + rebate)
       │      - Σ(buy + split)
       │      + Σ(currentValue of open positions)
       │  Category breakdown via market → mapped_category
       │
       ▼
  export_pnl_snapshots (→ wallet_pnl_snapshots table)
```

### PnL formula (validated to < $10 error vs Polymarket leaderboard)

```
PnL_wallet = Σ(SELL) + Σ(REDEEM) + Σ(MERGE) + Σ(REBATE)
           - Σ(BUY) - Σ(SPLIT)
           + Σ(currentValue of open positions)

currentValue = shares × curPrice (from /positions)
```

For category breakdown: each `/activity` event has an `asset` (token_id) → `condition_id` → `market_id` → `mapped_category`.

## 1. Data Loader: `load_activity.py`

**Endpoint**: `GET https://data-api.polymarket.com/activity?user={wallet}&limit=500&end={cursor}`

Key points:
- **Cursor-based pagination** (timestamp of last event - 1ms). The API rejects `offset > 3000`.
- 10-worker parallelism (same pattern as `load_trades_for_wallet.py`)
- Mapping `asset` → `condition_id` → `market_id` via `load_condition_map()`
- Mapping `market_id` → `category` via `SELECT id, mapped_category FROM markets`

```python
import concurrent.futures
import requests
import time
from datetime import datetime, timezone
from pandas import DataFrame
from sqlalchemy import create_engine, text

if 'data_loader' not in globals():
    from mage_ai.data_preparation.decorators import data_loader
if 'test' not in globals():
    from mage_ai.data_preparation.decorators import test

from default_repo.utils.db_helpers import load_condition_map

DATA_API = "https://data-api.polymarket.com"
PAGE_SIZE = 500
BATCH_WALLETS = 200

ACTIVITY_COLS = [
    "wallet", "market_id", "category", "activity_type",
    "side", "amount_usd", "asset", "timestamp", "tx_hash",
]


def fetch_activity_for_wallet(proxy: str) -> list[dict]:
    """Fetch ALL activity for a wallet using cursor pagination."""
    try:
        all_events = []
        end_cursor = None
        while True:
            params = {"user": proxy, "limit": PAGE_SIZE}
            if end_cursor:
                params["end"] = end_cursor
            resp = requests.get(
                f"{DATA_API}/activity",
                params=params,
                timeout=(5, 30),
            )
            if resp.status_code != 200:
                break
            batch = resp.json()
            if not batch:
                break
            all_events.extend(batch)
            if len(batch) < PAGE_SIZE:
                break
            # Cursor = last event timestamp - 1ms
            last_ts = batch[-1].get("timestamp")
            if last_ts:
                end_cursor = str(int(last_ts) - 1)
            else:
                break
            time.sleep(0.05)
        return all_events
    except requests.RequestException:
        return []


def classify_activity_type(event: dict) -> tuple[str, str | None]:
    """Classify event into (activity_type, side).

    Returns:
        activity_type: 'TRADE', 'REDEEM', 'MERGE', 'SPLIT', 'REBATE'
        side: 'BUY' or 'SELL' for TRADE, None otherwise
    """
    event_type = event.get("type", "").upper()
    if event_type == "TRADE":
        side = event.get("side", "").upper()
        if side in ("BUY", "SELL"):
            return ("TRADE", side)
        return ("TRADE", None)
    elif event_type in ("REDEEM", "MERGE", "SPLIT", "REBATE"):
        return (event_type, None)
    return ("UNKNOWN", None)


@data_loader
def load_data_from_api(tracked: DataFrame, *args, **kwargs) -> dict[str, DataFrame]:
    """Load activity + open positions for all tracked wallets.

    Returns dict with keys 'activity' and 'open_positions'.
    """
    if tracked.empty:
        return {
            "activity": DataFrame(columns=ACTIVITY_COLS),
            "open_positions": DataFrame(),
        }

    print("Loading condition_id → market_id and category maps...")
    cond_map = load_condition_map()

    engine = create_engine("postgresql://app:devpassword@postgres:5432/polymarket")
    market_cat = DataFrame(engine.execute(
        text("SELECT id AS market_id, mapped_category AS category FROM markets "
             "WHERE mapped_category IS NOT NULL")
    ).fetchall())
    cat_map = dict(zip(market_cat["market_id"], market_cat["category"]))
    engine.dispose()
    print(f"  {len(cond_map)} markets mapped, {len(cat_map)} with categories")

    proxy_wallets = tracked["main_wallet"].dropna().unique().tolist()
    n_wallets = len(proxy_wallets)
    print(f"Fetching activity for {n_wallets} wallets")

    event_rows = []
    done = 0
    t0 = time.time()

    for chunk_start in range(0, n_wallets, BATCH_WALLETS):
        chunk = proxy_wallets[chunk_start:chunk_start + BATCH_WALLETS]

        with concurrent.futures.ThreadPoolExecutor(max_workers=10) as executor:
            fut_map = {
                executor.submit(fetch_activity_for_wallet, pw): pw
                for pw in chunk
            }
            for fut in concurrent.futures.as_completed(fut_map):
                done += 1
                events = fut.result()
                pw = fut_map[fut]
                for ev in events:
                    cond_id = ev.get("conditionId")
                    market_id = cond_map.get(cond_id) if cond_id else None
                    if not market_id:
                        continue
                    activity_type, side = classify_activity_type(ev)
                    if activity_type == "UNKNOWN":
                        continue
                    tx_hash = ev.get("transactionHash") or ev.get("txHash")
                    asset = ev.get("asset")
                    ts = ev.get("timestamp")
                    amount = float(ev.get("size", 0) or 0) * float(ev.get("price", 0) or 0)
                    event_rows.append({
                        "wallet": pw,
                        "market_id": market_id,
                        "category": cat_map.get(market_id),
                        "activity_type": activity_type,
                        "side": side,
                        "amount_usd": amount,
                        "asset": asset,
                        "timestamp": datetime.fromtimestamp(int(ts), tz=timezone.utc) if ts else None,
                        "tx_hash": tx_hash,
                    })
        elapsed = time.time() - t0
        print(f"  {done}/{n_wallets} wallets, {len(event_rows)} events, {elapsed:.0f}s")

    # Also load open positions from PG for current value computation
    engine = create_engine("postgresql://app:devpassword@postgres:5432/polymarket")
    open_pos = DataFrame(engine.execute(
        text("""
            SELECT wallet, market_id, shares, avg_entry_price,
                   realized_pnl, unrealized_pnl
            FROM positions
            WHERE wallet = ANY(:wallets) AND status = 'OPEN'
        """),
        {"wallets": proxy_wallets},
    ).fetchall())
    engine.dispose()

    activity_df = DataFrame(event_rows, columns=ACTIVITY_COLS) if event_rows else DataFrame(columns=ACTIVITY_COLS)
    print(f"Total activity events: {len(activity_df)}, open positions: {len(open_pos)}")
    return {"activity": activity_df, "open_positions": open_pos}


@test
def test_output(result) -> None:
    assert "activity" in result, "Missing activity DataFrame"
    assert "open_positions" in result, "Missing open_positions DataFrame"
```

## 2. Transformer: `compute_pnl_from_activity.py`

Applies the cash flow formula to compute PnL per wallet with per-category breakdown.

```python
from datetime import date
from pandas import DataFrame, to_numeric, merge

if 'transformer' not in globals():
    from mage_ai.data_preparation.decorators import transformer
if 'test' not in globals():
    from mage_ai.data_preparation.decorators import test

SNAPSHOT_COLS = [
    "wallet", "snapshot_date",
    "total_pnl", "total_realized_pnl", "total_unrealized_pnl",
    "total_bought", "total_sold", "total_redeemed",
    "total_merged", "total_split", "total_rebates",
    "num_activity_events", "open_position_value",
    "category_breakdown",
]


def compute_pnl(data: dict) -> DataFrame:
    today = date.today()
    activity = data.get("activity", DataFrame())
    open_positions = data.get("open_positions", DataFrame())

    if activity.empty and open_positions.empty:
        print("No activity or open positions — returning empty DataFrame")
        return DataFrame(columns=SNAPSHOT_COLS)

    # Ensure numeric
    if not activity.empty:
        activity["amount_usd"] = to_numeric(activity["amount_usd"], errors="coerce").fillna(0)

    # --- Wallet-level PnL ---
    wallet_pnl = {}

    # Aggregate activity by wallet and type
    if not activity.empty:
        # Cash inflows
        sells = activity[(activity["activity_type"] == "TRADE") & (activity["side"] == "SELL")]
        redeems = activity[activity["activity_type"] == "REDEEM"]
        merges = activity[activity["activity_type"] == "MERGE"]
        rebates = activity[activity["activity_type"] == "REBATE"]

        # Cash outflows
        buys = activity[(activity["activity_type"] == "TRADE") & (activity["side"] == "BUY")]
        splits = activity[activity["activity_type"] == "SPLIT"]

        for wallet in activity["wallet"].unique():
            w_buys = buys[buys["wallet"] == wallet]["amount_usd"].sum()
            w_sells = sells[sells["wallet"] == wallet]["amount_usd"].sum()
            w_redeems = redeems[redeems["wallet"] == wallet]["amount_usd"].sum()
            w_merges = merges[merges["wallet"] == wallet]["amount_usd"].sum()
            w_splits = splits[splits["wallet"] == wallet]["amount_usd"].sum()
            w_rebates = rebates[rebates["wallet"] == wallet]["amount_usd"].sum()
            w_events = len(activity[activity["wallet"] == wallet])

            realized_pnl = w_sells + w_redeems + w_merges + w_rebates - w_buys - w_splits
            wallet_pnl[wallet] = {
                "wallet": wallet,
                "snapshot_date": today,
                "total_realized_pnl": round(realized_pnl, 2),
                "total_bought": round(w_buys, 2),
                "total_sold": round(w_sells, 2),
                "total_redeemed": round(w_redeems, 2),
                "total_merged": round(w_merges, 2),
                "total_split": round(w_splits, 2),
                "total_rebates": round(w_rebates, 2),
                "num_activity_events": w_events,
                "total_unrealized_pnl": None,  # filled from open positions below
                "open_position_value": None,
                "total_pnl": None,
            }

    # Compute open position value (unrealized PnL)
    open_value_by_wallet = {}
    if not open_positions.empty:
        for _, pos in open_positions.iterrows():
            w = pos["wallet"]
            open_value_by_wallet[w] = open_value_by_wallet.get(w, 0) + float(pos.get("unrealized_pnl", 0) or 0)

    # Merge open position values
    for wallet, val in open_value_by_wallet.items():
        if wallet not in wallet_pnl:
            wallet_pnl[wallet] = {
                "wallet": wallet,
                "snapshot_date": today,
                "total_realized_pnl": 0,
                "total_bought": 0,
                "total_sold": 0,
                "total_redeemed": 0,
                "total_merged": 0,
                "total_split": 0,
                "total_rebates": 0,
                "num_activity_events": 0,
                "total_unrealized_pnl": None,
                "open_position_value": None,
                "total_pnl": None,
            }
        wallet_pnl[wallet]["total_unrealized_pnl"] = round(val, 2)
        wallet_pnl[wallet]["open_position_value"] = round(val, 2)
        wallet_pnl[wallet]["total_pnl"] = round(
            (wallet_pnl[wallet]["total_realized_pnl"] or 0) + val, 2
        )

    # Fill total_pnl for wallets with no open positions
    for w in wallet_pnl:
        if wallet_pnl[w]["total_pnl"] is None:
            wallet_pnl[w]["total_pnl"] = wallet_pnl[w]["total_realized_pnl"]

    # --- Category breakdown ---
    category_breakdown = {}
    if not activity.empty and "category" in activity.columns:
        cat_activity = activity[activity["category"].notna()]
        if not cat_activity.empty:
            for (wallet, cat), grp in cat_activity.groupby(["wallet", "category"]):
                cat_sells = grp[(grp["activity_type"] == "TRADE") & (grp["side"] == "SELL")]["amount_usd"].sum()
                cat_buys = grp[(grp["activity_type"] == "TRADE") & (grp["side"] == "BUY")]["amount_usd"].sum()
                cat_redeems = grp[grp["activity_type"] == "REDEEM"]["amount_usd"].sum()
                cat_merges = grp[grp["activity_type"] == "MERGE"]["amount_usd"].sum()
                cat_splits = grp[grp["activity_type"] == "SPLIT"]["amount_usd"].sum()
                cat_rebates = grp[grp["activity_type"] == "REBATE"]["amount_usd"].sum()

                cat_realized = cat_sells + cat_redeems + cat_merges + cat_rebates - cat_buys - cat_splits

                if wallet not in category_breakdown:
                    category_breakdown[wallet] = {}
                category_breakdown[wallet][cat] = {
                    "total_realized_pnl": round(cat_realized, 2),
                    "total_bought": round(cat_buys, 2),
                    "total_sold": round(cat_sells, 2),
                    "total_redeemed": round(cat_redeems, 2),
                    "num_events": len(grp),
                }

    # Attach category breakdown
    for w in wallet_pnl:
        wallet_pnl[w]["category_breakdown"] = category_breakdown.get(w)

    rows = list(wallet_pnl.values())
    print(f"Computed PnL for {len(rows)} wallets")
    return DataFrame(rows) if rows else DataFrame(columns=SNAPSHOT_COLS)


@transformer
def transform_df(data: dict, *args, **kwargs) -> DataFrame:
    return compute_pnl(data)


@test
def test_output(df) -> None:
    assert df is not None, "Output is undefined"
    if not df.empty:
        assert "total_pnl" in df.columns, "Missing total_pnl"
        for _, row in df.iterrows():
            # total_pnl should equal realized + unrealized
            if row["total_unrealized_pnl"] is not None:
                expected = round((row["total_realized_pnl"] or 0) + row["total_unrealized_pnl"], 2)
                assert abs((row["total_pnl"] or 0) - expected) < 0.01, (
                    f"total_pnl mismatch for {row['wallet']}: "
                    f"{row['total_pnl']} != {expected}"
                )
```

## 3. Data Exporter: `export_pnl_snapshots.py`

UPSERT into `wallet_pnl_snapshots` with `ON CONFLICT DO UPDATE`.

```python
from pandas import DataFrame
from sqlalchemy import create_engine, text

if 'data_exporter' not in globals():
    from mage_ai.data_preparation.decorators import data_exporter
if 'test' not in globals():
    from mage_ai.data_preparation.decorators import test

from default_repo.utils.db_helpers import safe_value

DATABASE_URL = "postgresql://app:devpassword@postgres:5432/polymarket"

NUM_COLS = [
    "total_pnl", "total_realized_pnl", "total_unrealized_pnl",
    "total_bought", "total_sold", "total_redeemed",
    "total_merged", "total_split", "total_rebates",
    "open_position_value",
]
STR_COLS = ["wallet"]
INT_COLS = ["num_activity_events"]
JSON_COLS = ["category_breakdown"]


@data_exporter
def export_data(df: DataFrame, **kwargs) -> None:
    if df.empty:
        print("No PnL snapshots to export")
        return
    print(f"Exporting {len(df)} wallet PnL snapshots")
    engine = create_engine(DATABASE_URL)
    with engine.begin() as conn:
        for _, row in df.iterrows():
            params = {"snapshot_date": row["snapshot_date"]}
            for c in STR_COLS:
                params[c] = row.get(c)
            for c in INT_COLS:
                params[c] = safe_value(row.get(c))
            for c in NUM_COLS:
                params[c] = safe_value(row.get(c))
            for c in JSON_COLS:
                v = row.get(c)
                params[c] = safe_value(v)

            conn.execute(
                text("""
                    INSERT INTO wallet_pnl_snapshots (
                        wallet, snapshot_date,
                        total_pnl, total_realized_pnl, total_unrealized_pnl,
                        total_bought, total_sold, total_redeemed,
                        total_merged, total_split, total_rebates,
                        num_activity_events, open_position_value,
                        category_breakdown
                    ) VALUES (
                        :wallet, :snapshot_date,
                        :total_pnl, :total_realized_pnl, :total_unrealized_pnl,
                        :total_bought, :total_sold, :total_redeemed,
                        :total_merged, :total_split, :total_rebates,
                        :num_activity_events, :open_position_value,
                        :category_breakdown
```

## 8. Backfill Script

Create `scripts/backfill_pnl.py`:

```python
#!/usr/bin/env python3
"""One-shot backfill: compute PnL for all wallets from /activity and write to wallet_pnl_snapshots.

Usage:
    python scripts/backfill_pnl.py [--wallet 0x...]
"""

import argparse
import sys
sys.path.insert(0, ".")

from datetime import date
from pandas import DataFrame
from sqlalchemy import create_engine, text

from magic.default_repo.data_loaders.load_activity import (
    fetch_activity_for_wallet, classify_activity_type, ACTIVITY_COLS,
)
from magic.default_repo.utils.db_helpers import load_condition_map

DATABASE_URL = "postgresql://app:devpassword@postgres:5432/polymarket"


def backfill_wallet(wallet: str, cond_map: dict, cat_map: dict, engine):
    """Compute PnL for a single wallet and upsert into wallet_pnl_snapshots."""
    events = fetch_activity_for_wallet(wallet)
    if not events:
        print(f"  {wallet}: no activity")
        return

    # Map events
    rows = []
    for ev in events:
        cond_id = ev.get("conditionId")
        market_id = cond_map.get(cond_id) if cond_id else None
        if not market_id:
            continue
        activity_type, side = classify_activity_type(ev)
        if activity_type == "UNKNOWN":
            continue
        amount = float(ev.get("size", 0) or 0) * float(ev.get("price", 0) or 0)
        rows.append({
            "wallet": wallet,
            "market_id": market_id,
            "category": cat_map.get(market_id),
            "activity_type": activity_type,
            "side": side,
            "amount_usd": amount,
        })

    if not rows:
        return

    # Compute PnL (simplified — same logic as transformer)
    df = DataFrame(rows)
    buys = df[(df["activity_type"] == "TRADE") & (df["side"] == "BUY")]["amount_usd"].sum()
    sells = df[(df["activity_type"] == "TRADE") & (df["side"] == "SELL")]["amount_usd"].sum()
    redeems = df[df["activity_type"] == "REDEEM"]["amount_usd"].sum()
    merges = df[df["activity_type"] == "MERGE"]["amount_usd"].sum()
    splits = df[df["activity_type"] == "SPLIT"]["amount_usd"].sum()
    rebates = df[df["activity_type"] == "REBATE"]["amount_usd"].sum()

    realized_pnl = sells + redeems + merges + rebates - buys - splits

    # Get open position value
    result = engine.execute(
        text("SELECT COALESCE(SUM(unrealized_pnl), 0) FROM positions "
             "WHERE wallet = :wallet AND status = 'OPEN'"),
        {"wallet": wallet},
    ).scalar()
    open_value = float(result or 0)

    total_pnl = realized_pnl + open_value

    engine.execute(
        text("""
            INSERT INTO wallet_pnl_snapshots (
                wallet, snapshot_date, total_pnl, total_realized_pnl,
                total_unrealized_pnl, total_bought, total_sold,
                total_redeemed, total_merged, total_split, total_rebates,
                num_activity_events, open_position_value
            ) VALUES (
                :wallet, :today, :total_pnl, :realized_pnl,
                :unrealized_pnl, :bought, :sold,
                :redeemed, :merged, :split, :rebates,
                :events, :open_value
            )
            ON CONFLICT (wallet, snapshot_date) DO UPDATE SET
                total_pnl = EXCLUDED.total_pnl,
                total_realized_pnl = EXCLUDED.total_realized_pnl,
                total_unrealized_pnl = EXCLUDED.total_unrealized_pnl,
                computed_at = NOW()
        """),
        {
            "wallet": wallet,
            "today": date.today(),
            "total_pnl": round(total_pnl, 2),
            "realized_pnl": round(realized_pnl, 2),
            "unrealized_pnl": round(open_value, 2),
            "bought": round(buys, 2),
            "sold": round(sells, 2),
            "redeemed": round(redeems, 2),
            "merged": round(merges, 2),
            "split": round(splits, 2),
            "rebates": round(rebates, 2),
            "events": len(rows),
            "open_value": round(open_value, 2),
        },
    )
    print(f"  {wallet}: PnL={total_pnl:.2f}, events={len(rows)}")


def main():
    parser = argparse.ArgumentParser(description="Backfill PnL from /activity")
    parser.add_argument("--wallet", help="Specific wallet to backfill (default: all)")
    args = parser.parse_args()

    engine = create_engine(DATABASE_URL)
    cond_map = load_condition_map()
    cat_map = dict(engine.execute(
        text("SELECT id, mapped_category FROM markets WHERE mapped_category IS NOT NULL")
    ).fetchall())

    if args.wallet:
        wallets = [args.wallet]
    else:
        wallets = [r[0] for r in engine.execute(
            text("SELECT DISTINCT wallet FROM trades")
        ).fetchall()]

    print(f"Backfilling PnL for {len(wallets)} wallets...")
    for i, w in enumerate(wallets, 1):
        backfill_wallet(w, cond_map, cat_map, engine)
        if i % 50 == 0:
            print(f"  progress: {i}/{len(wallets)}")

    engine.dispose()
    print("Backfill complete")


if __name__ == "__main__":
    main()
```
